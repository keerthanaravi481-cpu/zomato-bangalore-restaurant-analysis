# Zomato Bangalore Restaurant Analysis

## Objective
Explore ~51,000 Bangalore restaurants listed on Zomato to identify what drives
higher ratings — cost, cuisine, locality, and online ordering availability.

## Dataset
[Zomato Bangalore Restaurants](https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants) (Kaggle)

## Tools
Python (Pandas, Seaborn), SQL (SQLite window functions), Power BI, Google Colab

## Process
1. Cleaned messy real-world data (rating format, cost formatting, duplicates)
2. Explored rating distribution, cost-vs-rating relationship, and top cuisines/localities
3. Used SQL window functions (RANK) to find the top-rated restaurants per locality
4. Built a Power BI dashboard summarizing rating, cost, and cuisine trends
